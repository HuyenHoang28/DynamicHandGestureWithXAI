# Paper source

`DATE_NeuroSymbolic_Manuscript.pdf` is the current 24-page manuscript for the
DATE 27-class neuro-symbolic system. It reports a ten-run proposed-fusion mean
of `96.40 ± 0.17%` on 1,229 test clips and compares against Sparse-ST-GCN,
SignBart, ProtoGCN, and published DATE methods.

The manuscript number is not interchangeable with a single local checkpoint.
For the reproducible validation-selected checkpoint, use the evidence and
caveats in `docs/NHAT_KY_THAY_DOI_VI.md` (mục 6) và `docs/KIEN_TRUC_CHI_TIET_VI.md` (mục 10).
